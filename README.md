# HOW TO RUN

Currently, there is no executable version of this game yet. It will be released after the complete implementation of the Beyond prestige layer. 

To run the game for now, copy the '.vscode/', 'core/', 'utilis/' and 'Program.cs' files into a folder and compile them through any C# compiler (like VS Code).
